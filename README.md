Student Management System

A console-based Student Management System developed using the C programming language. This project helps manage student records through a simple menu-driven interface.

Features

- Add new student records
- Display all student records
- Search students by roll number
- Search students by full or partial name
- Calculate student grades
- Update existing student details
- Delete student records
- Sort students by roll number
- Sort students by marks
- Calculate class statistics
- Store student records permanently using file handling
- User-friendly console interface

Technologies Used

- Language: C
- Compiler: GCC
- Editor: Visual Studio Code
- Concepts: Structures, Functions, Arrays, File Handling, Searching, Sorting

How to Run

1. Install GCC

Make sure GCC is installed and configured on your system.

2. Clone the Repository

git clone YOUR_GITHUB_REPOSITORY_URL

3. Open the Project Folder

cd Student-Management-System

4. Compile the Program

gcc -Wall -Wextra main.c -o student.exe

5. Run the Program

On Windows PowerShell:

.\student.exe
